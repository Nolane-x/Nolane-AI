# R2.52 → R2.53 Evolution

R2.52 expanded causal repair across repository files. R2.53 changes a different axis: the external runtime can now treat *reasoning/control behaviors themselves* as retrievable, verifiable artifacts.

## What changed

- Added an objective cognitive-state snapshot rather than relying on model self-report.
- Added deficit detection for factual, search, verification, planning, representation, tool, memory, contradiction, resource and related control gaps.
- Added a provenance-hashed procedural knowledge library and trusted primitive registry.
- Added a safe procedure compiler with capability, risk, cost and verifier gates; arbitrary retrieved code execution is forbidden.
- Added cognition-time procedure routing, execution, verification, counterexample memory and per-procedure credit assignment.
- Added a bridge to the pre-existing R2.1 cognition-time factual retriever.
- Added a 38-family / 312-suboperator externalization taxonomy with honest implementation-status labels.
- Recalibrated the internal readiness metric to remove earlier score inflation.

## What did not change

- The neural model weights are not automatically improved.
- R2.53 does not autonomously invent a missing procedure from raw knowledge yet.
- Procedure cards, deficit mappings and primitive executors still encode host priors.
- The mechanism benchmark is synthetic and deterministic.
- Nolane World W5 remains non-converged.
- Coding-AGI readiness therefore remains 44.5/100 pending external transfer.
