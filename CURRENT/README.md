# CURRENT — Canonical Architecture Authority

`CURRENT/` is the authoritative description of the present Nolane AI research architecture.

If a historical R-series document, root-level delivery note, old README section, archived design, or compatibility module conflicts with `CURRENT/`, **`CURRENT/` wins for current architecture**. Historical material remains valuable evidence of how the system evolved, but it does not redefine the present model.

Current architecture is research-only: one Nolane AI research system with exactly 67 permanent AI Identities, shared/regional/private Neural and External composition, explicit memory/skills/evidence, and independently evolvable identity profiles. A future user-facing AI Agent product is outside current scope.

Canonical source hierarchy:

```text
CURRENT/                 architecture law
shared/                  global Neural/External source
regions/<region-id>/     regional overlay source
ai/<agent-id>/           individual source + generated resolved dossier
nolane.ai                canonical loader/resolver
```

Generated `ai/*/RESOLVED.json` and `ai/*/RESOLVED.md` are derived views. They are never manual write authority.
