# Canonical Terminology

## Nolane AI
The whole current research system.

## AI Identity
One permanent cognitive member of the fixed 67-member organization. This is the canonical current term for Central, Chiefs, and Specialists.

## Neural Core
Trainable/internal neural intelligence: architecture, representation, learning, adaptation, neural memory, inference, checkpoints, training state, and neural evaluation.

## External Core
The umbrella for non-neural capabilities available to an AI Identity: tools, engines, runtimes, graphs, stores, retrievers, executors, controllers, analyzers, environments, and related capability substrates.

## Tool
A capability subtype inside External Core. `External Core + Tool` as two peer layers is deprecated; Tool is contained by External Core.

## AI Agent
**Reserved for a future product-level autonomous system.** It is not the current name for the 67 research identities and must not be used to silently introduce UI/application/product scope into present architecture.

## Resolved View
A generated, non-authoritative projection that composes shared + regional + private source for one AI Identity so humans and machines can inspect its complete effective state from one entry point.
