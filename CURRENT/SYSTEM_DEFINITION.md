# System Definition

**Nolane AI** is the whole experimental compact cognitive research system. It is not synonymous with Nolane Central, a single neural model, or a future application.

The current organization contains exactly 67 permanent AI Identities: 1 Nolane Central, 15 Regional Chiefs, and 51 permanent Specialists. Every Chief is direct-work capable; Chiefs are not pure dispatchers.

An identity resolves from canonical layers:

```text
identity
+ shared Neural Core
+ regional Neural overlay (when applicable)
+ private Neural Core
+ shared External Core
+ regional External Core (when applicable)
+ private External Core
+ personal memory namespace
+ personal skill namespace
```

Epoch 0 preserves accepted physical parameter accounting: 56M shared parameters plus one local delta of 40M Central / 34M Chief / 20M senior specialist / 8M specialist. Regional Neural overlays are logical specialization/version layers with zero separately-accounted physical parameters until an explicit future parameter migration is accepted.
