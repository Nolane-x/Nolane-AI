# R2.57 → R2.58 Evolution

R2.57 could reuse learned cognitive abstractions, but its strongest external composition result still depended on a harness-selected endpoint probe that exposed the normalized-progress subgoal. R2.58 moves that intervention choice into the runtime.

R2.58 mines **identity-exposure schemas** from the learned vocabulary itself, rejects redundant controls, compiles schema roles onto opaque task fields using observation profiles rather than semantic names, queries an I/O-only oracle under bounded interventions, and synthesizes the induced latent subgoal. A bounded CEGIS loop repairs sparse-probe overfit before the latent expression is eligible to seed the full target.

Crucially, a probe is not accepted merely because it yields a simple function. The discovered latent must pass transformed challenge contexts, causally unlock the original full synthesis under the frozen budget, and then the full expression must pass the original challenge. Oracle calls, interventions and synthesis candidates remain budgeted and fail closed.

Frozen Phase A reports three genuine affine active-discovery worlds plus three transparent field-renaming metamorphic replays: R2.57 harness-free 0/6, R2.58 6/6, zero false accepts, with a maximum of 77 discovery oracle calls and 8 interventions. Hosted transfer against pinned `ufunclab.linearstep` uses zero manual probe rows and zero field hints; the harness-free base fails while R2.58 passes 8/8 challenge and 24/24 heldout cases.

The boundary remains strict. This is bounded active experiment/subgoal discovery inside the finite pure R2.56/R2.57 evaluator. It does not establish open-ended experimental science, effectful tool invention, arbitrary program synthesis, or broad repository coding autonomy.
